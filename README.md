# COMP4010 Project 2: Global Population & Demographic Insights Dashboard

An interactive data visualization dashboard for exploring worldwide demographic trends using data from Our World in Data.

## Overview

This project visualizes global demographic indicators such as:

- Birth rate
- Death rate
- Life expectancy
- Fertility rate
- Net migration
- Population growth

The dashboard is designed around an interactive globe interface that allows users to explore demographic patterns across countries and regions over time.

## Dataset
Data sources: United Nations, World Population Prospects (2024) — processed by Our World in Data.

Original dataset and explorer:  
https://ourworldindata.org/explorers/population-and-demography

Please credit all listed sources when using or redistributing this project.  
Data provided by third-party sources through Our World in Data remains subject to the original provider’s license terms.

## Project Goals

- Make large-scale demographic data easier to understand
- Identify regional and global population trends
- Provide an engaging and interactive visualization experience
- Support exploratory analysis through interactive dashboards
